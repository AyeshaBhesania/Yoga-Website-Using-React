# Yoga Website

A responsive yoga studio website built using **React**, **Vite**, and **Tailwind CSS**.

## About the Project

This project is a yoga studio website designed to showcase yoga classes, membership plans, wellness services, products, and customer testimonials.

## Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript
- React Icons
- Flowbite React

## Installation and Setup

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/AyeshaBhesania/Yoga-Website-Using-React.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Yoga-Website-Using-React
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
